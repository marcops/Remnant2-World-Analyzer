# Remnant 2 World Analyzer

Reads **Remnant 2** saves in the browser: what is in your world and what you still need — the
Remnant 2 sibling of [Remnant World Analyzer](https://github.com/marcops/Remnant-World-Analyzer)
(Remnant: From the Ashes).

**Status:** reads your characters and shows every collectible of the game, base game and all DLCs — weapons,
mods, mutators, armor, amulets, rings, relics, relic fragments, traits, archetypes, prisms, concoctions,
consumables and quest items — as had or missing, by category and by world/DLC, each with its icon, what it
does and how to get it. Reads your world too: campaign and adventure, every area with its bosses, dungeons,
events, items on the ground, trait books and simulacrums, a map, tips, your build's DPS, and a save editor.
How the saves and the game files were worked out: [docs/SAVE-FORMAT.md](docs/SAVE-FORMAT.md).

## Sources

- **The game files** — what exists and the exact path the save uses (`tools/utoc.mjs`, `tools/catalog.mjs`).
- **[lib.remnant2.analyzer](https://github.com/AndrewSav/lib.remnant2.analyzer)** item database (MIT,
  © 2023-2024 Andrew Savinykh) — the game's item names, how to get each item, Hardcore/co-op flags, which
  weapon a mod comes with.
- **[lib.remnant2.saves](https://github.com/AndrewSav/lib.remnant2.saves)** (MIT, © Andrew Savinykh) — the
  world save's level/actor layout and the checksum, which `js/gvas.js`, `js/world.js` and `js/sav.js` follow.
- **[Remnant 2 wiki](https://remnant2.wiki.fextralife.com/)** (Fextralife) — effects, tips and the item icons
  (`tools/wiki.mjs`). Item art © Gunfire Games.

## Use

- **Automatic (Windows):** download the project and double-click **Start.bat**. It serves the page at
  http://localhost:8775 and reads the saves straight from
  `%USERPROFILE%\Saved Games\Remnant2\Steam\<number>`, updating when the game saves.
  `Start.bat -SaveDir "D:\other\folder"` for another folder.
- **Manual:** open the page and drop `profile.sav` and `save_N.sav` on it.

Nothing is installed and nothing leaves your PC: the files are read in the browser.

## Development

- `js/sav.js` — the .sav container: header and zlib chunks → the decompressed save.
- `js/app.js` — the page.
- `server.ps1` / `Start.bat` — local server: the page, the save folder, backups.
- `js/character.js` — the characters of profile.sav: archetypes, inventory, traits.
- `js/world.js` — the rolled worlds of save_N.sav: areas, events, loot, explored cells, tiles.
- `js/editor.js` — the save editor (in-place values; `js/sav.js` recompresses with the CRC-32).
- `js/catalog.js` — every collectible, generated by `tools/catalog.mjs "<Remnant2 folder>" [profile.sav]` from
  the game's .utoc indexes (`tools/utoc.mjs`) and the item database (`tools/source/db.json`, from
  lib.remnant2.analyzer's `db.json`).
- `js/wiki.js`, `img/items/` — effects, tips and icons, generated by `tools/wiki.mjs` (pages cached in
  `tools/source/wiki/`), icons at the wiki's size (the few over 50 KB shrunk to 200 px by `tools/icons.ps1`).
- `tools/decompress.mjs` — writes a decompressed copy of a save, for studying it.
- Tests: `R2_SAVE=<…\save_0.sav> R2_PROFILE=<…\profile.sav> node --test test/sav.test.mjs`
